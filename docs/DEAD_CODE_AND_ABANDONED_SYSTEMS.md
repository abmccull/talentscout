Decision vocabulary: **DELETE** obsolete executable behavior with no valid consumer; **RESTORE** a useful promised capability that requires a real implementation; **MERGE** duplicate authorities; **REFACTOR** a useful system with an integration defect; **KEEP** intentional infrastructure, compatibility or scoped future work. "Removed" below describes this implementation's source changes, not deletion of historical save data. Parent audit/report records integrated verification and unresolved acceptance gates.

## Coverage and removal safeguards

- `GAME_SYSTEM_MAP.md` inventories every meaningful engine directory and separates truth, knowledge, UI, background simulation, future-mode scope and persistence ownership.
- No route, table, migration, save field, worker, online service or whole mode was deleted in this cleanup.
- Imports/re-exports and exact identifier searches were checked before removal. Typecheck is the final local check for missed TypeScript consumers; it does not prove external integrations or future untracked plugins.
- The existing architecture audit checks cycles/module budgets rather than complete reachability, and its static import scanner does not establish dynamic-route usage. It is not used as a blanket deletion oracle.
- No `RESTORE` row is presented as completed because a roadmap exists. Remaining findings require implementation or a documented product decision, plus execution evidence, before the overall gameplay system can be called ready.

- Transfer willingness: fallback is parenthesized before the 0.75 threshold; low/high/missing-value tests pass.

Existing unlocked IDs/timestamps remain. No new reward is inferred from hidden PA or generated wonderkid tiers.

- Private passes: existing report/case/review infrastructure is restored as an actual decision path with Inbox/History/timeline feedback, no commercial/reputation farming reward and no automatic revisit task.

International football remains a bounded alumni milestone abstraction; full national-team competition is outside this Youth/shared-world scope. Future-mode and online gates remain intentional.
